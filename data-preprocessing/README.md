# Data Preprocessing - ROKKUS

Folder ini berisi hasil pekerjaan analisis dan preprocessing data untuk proyek Capstone UMKM ROKKUS Mardani Raya.

## Isi Folder
- notebooks/: Notebook analisis dan preprocessing.
- data/processed/: Dataset hasil preprocessing.
- outputs/: Hasil analisis dan laporan kualitas data.

Dataset yang digunakan merupakan dataset sintetis periode 1–30 September 2026.
