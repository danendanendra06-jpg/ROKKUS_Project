# Data - ROKKUS Project

Folder ini berisi dataset dan hasil pengolahan data yang digunakan dalam Capstone Project ROKKUS Mardani Raya.

## Struktur Folder

### 1. data-preprocessing
Berisi data hasil proses data cleaning, validasi, dan preprocessing yang dilakukan untuk menyiapkan dataset sebelum digunakan pada tahap analisis maupun pengembangan model AI.

### 2. data-science
Berisi file dan hasil pekerjaan Data Science, meliputi:
- Dataset bahan baku dan produk jadi.
- Dataset stok dan transaksi.
- Notebook pengolahan dan analisis data.
- Hasil Exploratory Data Analysis (EDA).
- Hasil klasifikasi status stok.
- Visualisasi dan ringkasan hasil analisis.
- Data Dictionary sebagai penjelasan setiap kolom dataset.

## Sumber dan Jenis Data

Dataset yang digunakan dalam proyek ini merupakan data sintetis (dummy), bukan data transaksi asli ROKKUS Mardani Raya.

Data sintetis digunakan karena data operasional asli UMKM tidak diberikan kepada tim. Tim sempat mempertimbangkan penggunaan dataset publik, tetapi belum menemukan dataset yang sesuai dengan kebutuhan proyek.

Khusus dataset bahan baku, data disusun berdasarkan perkiraan kebutuhan bahan dari menu yang dijual ROKKUS. Informasi detail mengenai bahan baku belum diperoleh secara langsung dari pemilik UMKM saat wawancara.

Dataset dibuat untuk mensimulasikan proses pencatatan stok, barang masuk, barang keluar, dan pemantauan persediaan.

## Catatan

- Seluruh data merupakan data simulasi untuk kebutuhan pengembangan dan pengujian proyek.
- Data tidak menggambarkan kondisi stok aktual ROKKUS.
- Hasil analisis dan klasifikasi hanya berlaku berdasarkan dataset sintetis yang digunakan.
- Dataset dapat diperbarui apabila tersedia informasi bahan baku dan data operasional yang telah dikonfirmasi oleh pihak UMKM.
